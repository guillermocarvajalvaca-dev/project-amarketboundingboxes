## 4. Epistemic rules

- `OBSERVED`: read directly.
- `EXECUTED`: demonstrated by a recorded run.
- `INFERRED`: reasonable but not demonstrated.
- `UNKNOWN`: evidence absent.
- `NOT_RUN`: not executed.
- `BLOCKED`: required evidence/access missing.

No inferred category, metric, latency or result may be presented as observed.
