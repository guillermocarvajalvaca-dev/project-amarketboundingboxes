# Checklist de protección de `main`

- [ ] Prohibir push directo a `main`.
- [ ] Exigir pull request antes de merge.
- [ ] Exigir al menos una aprobación.
- [ ] Invalidar aprobaciones cuando cambie el PR.
- [ ] Exigir resolución de conversaciones.
- [ ] Exigir revisión CODEOWNERS cuando aplique.
- [ ] Bloquear force-push y eliminación de `main`.
- [ ] Exigir checks cuando exista CI real.
- [ ] Probar la regla con un PR pequeño de documentación.
- [ ] Registrar evidencia en `EVIDENCE_LEDGER.csv`.

No se declara protección activa hasta observar la configuración o probarla.
