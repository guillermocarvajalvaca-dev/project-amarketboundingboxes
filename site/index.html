01 · Problema

¿Qué construimos?

Un sistema de visión computacional capaz de localizar un producto dentro de una imagen mediante una bounding box. El problema es de detección monoclase: todos los objetos pertenecen a la clase product.

Entrada

Imagen de un producto.

Detector

YOLO11n entrenado para detectar una única clase.

Salida

Coordenadas de la bounding box y confianza de la detección.

07 · Reproducibilidad

No basta con obtener una buena métrica

El proyecto incorpora mecanismos para demostrar qué datos, configuración y modelo produjeron los resultados.

SHA-256

Se utilizan hashes como huellas digitales para comprobar la integridad de artefactos.

Seed

La semilla permite controlar componentes aleatorios del pipeline.

Configuración

El entorno y la configuración se documentan para facilitar la reproducción.

Test congelado

El flujo contractual separa entrenamiento, selección mediante validation y evaluación final sobre test.

08 · Explicación simple

El proyecto en lenguaje sencillo

1. Conseguimos ejemplos

Reunimos imágenes de productos y registramos de dónde proviene cada una.

2. Le enseñamos dónde mirar

Cada producto recibe una caja que indica al modelo dónde está el objeto.

3. Practica

El modelo observa ejemplos del conjunto de entrenamiento y aprende patrones visuales.

4. Lo examinamos

Finalmente evaluamos el modelo con imágenes que no utilizó para aprender.
